# بازآرایی Frontend پروفایل — Phase 10

## محدوده و سازمان‌دهی

در فاز ۱۰ رفتار backend، قرارداد API، ذخیره‌سازی JSON و روش authorization تغییر نکرده است.
منطق صفحه پروفایل از JavaScript و CSS درون‌خطی به `static/js/profile-page.js`،
`static/js/profile-access-manager.js` و `static/css/profile.css` منتقل شده است. قالب فقط داده
نرمال‌شده و تأییدشده سمت سرور را در بلوک‌های JSON امن قرار می‌دهد و event handler درون‌خطی ندارد.
هیچ framework جدید یا منبع writable دیگری افزوده نشده است.

## قرارداد مدیر دسترسی

مدیر بصری همچنان برای هر کارخانه یک کارت، برای هر ماژول یک ردیف، و دقیقاً یک selector سطح
`NONE / READ / WRITE / MODIFY` دارد. ماژول‌ها و کارخانه‌ها فقط از metadata تولیدشده از رجیستری
canonical سمت سرور می‌آیند و `auth` نمایش داده نمی‌شود. Desk نیز یک selector دارد، اما گزینه
`NONE` برای آن ارائه نمی‌شود؛ READ ضمنی فقط برای نمایش سطح مؤثر استفاده می‌شود و انتخاب READ
یک grant زائد در JSON ذخیره نمی‌کند. سطح‌های WRITE و MODIFY صریح همچنان قابل ذخیره‌اند.

## ایمنی rendering و درخواست

رشته‌های کارخانه، ماژول و خلاصه دسترسی با `textContent` و DOM API ساخته می‌شوند و در
`innerHTML` قرار نمی‌گیرند. رکورد کاربر دیگر در `data-*` دکمه مدیریت کپی نمی‌شود؛ دکمه فقط شناسه
را نگه می‌دارد و داده نرمال‌شده modal یک بار از JSON امن صفحه خوانده می‌شود.

helper درخواست صفحه پاسخ را پیش از JSON parsing با `Content-Type` بررسی می‌کند تا HTML خطای 403
یا صفحه ورود به‌عنوان JSON parse نشود. خطاهای اعتبارسنجی/تعارض/ذخیره و شبکه پیام فارسی عمومی
دارند، ارسال‌های تکراری تا پایان درخواست غیرفعال می‌شوند، و فیلدهای گذرواژه پس از موفقیت، خطا یا
بستن modal پاک می‌شوند. اگر برنامه token استاندارد CSRF را در meta ارائه کند، helper آن را در
`X-CSRFToken` می‌فرستد؛ این فاز سازوکار امنیتی backend تازه‌ای معرفی نکرده است.

## قراردادهای حفظ‌شده

- دو نقش مدیر سطح بالا همچنان دسترسی کامل ضمنی و موازی دارند و `job_title` توصیفی است.
- Desk برای کاربر فعال حداقل READ می‌ماند و widgetهای میز کار همچنان به مجوز ماژول منبع وابسته‌اند.
- denial صفحه عادی همچنان صفحه فارسی RTL با status 403 و denial API همچنان JSON با status 403 است.
- audit واقعی با زمان canonical و نمایش جلالی دست‌نخورده باقی مانده است.
- ایجاد/ویرایش کاربر، بازنشانی گذرواژه، چرخه فعال‌بودن حساب، ایجاد کارخانه و انتشار پویای کارخانه حفظ شده‌اند.

Phase 11 در این تغییر آغاز نشده است.
