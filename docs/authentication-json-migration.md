# مهاجرت احراز هویت به JSON در ویندوز

## علت پیام راه‌اندازی

ورود دیگر فایل قدیمی `Data/Overall/auth_data.xlsx` را در زمان اجرای برنامه نمی‌خواند. فایل
`instance/app_data.json` منبع یگانه و معتبر کاربران است و باید یک بار، پیش از نخستین ورود،
از فایل قدیمی ساخته شود. برنامه در صورت نبودن این فایل، به‌جای نمایش traceback، پیام راه‌اندازی
فارسی با وضعیت 503 نشان می‌دهد و هرگز به Excel بازنمی‌گردد.

## دستور یک‌باره

در PowerShell یا Command Prompt، ابتدا به پوشه اصلی پروژه بروید و سپس اجرا کنید:

```powershell
python -m scripts.migrate_auth_to_json
```

مسیرهای پیش‌فرض دستور عبارت‌اند از:

- ورودی فقط‌خواندنی: `Data/Overall/auth_data.xlsx`
- خروجی معتبر: `instance/app_data.json`

اگر متغیر `APP_DATA_FILE` تنظیم شده باشد، همان مسیر مقصد استفاده می‌شود. مسیرهای دیگری را نیز
می‌توان صریح وارد کرد:

```powershell
python -m scripts.migrate_auth_to_json "B:\secure\auth_data.xlsx" "B:\secure\app_data.json"
```

دستور از بازنویسی مقصد موجود خودداری می‌کند. پس از موفقیت، برنامه را دوباره اجرا کنید. کاربر
مهاجرت‌یافته با گذرواژه قبلی وارد می‌شود و برای تعیین یک گذرواژه امن جدید هدایت خواهد شد. هش‌های
ناشناخته یا ناسازگار وارد فرایند حدس یا گذرواژه پیش‌فرض نمی‌شوند و حساب مربوطه نیازمند بازنشانی
کنترل‌شده باقی می‌ماند.

فایل Excel منبع زمان اجرا نیست و نباید پس از مهاجرت برای نوشتن کاربران استفاده شود. نسخه پشتیبان
آن را خارج از مسیر اجرای برنامه و با دسترسی محدود نگهداری کنید.

## ایجاد نخستین مدیر فناوری اطلاعات

اگر فایل قدیمی حساب مورد نظر را ندارد، مدیر اولیه را با دستور تعاملی زیر بسازید:

```powershell
python -m scripts.bootstrap_it_admin
```

نام کاربری پیش‌فرض پرسش تعاملی `Mohsen1224` است. ایمیل، نام کامل، گذرواژه و تکرار آن در همان
لحظه دریافت می‌شوند. گذرواژه در ترمینال نمایش داده نمی‌شود، در آرگومان فرمان یا کد منبع قرار
نمی‌گیرد و فقط هش نمک‌دار تولیدشده توسط Werkzeug در JSON نوشته می‌شود. پس از ایجاد، ورود با نام
کاربری یا ایمیل، بدون حساسیت به بزرگی و کوچکی حروف، امکان‌پذیر است.

این دستور فقط راه‌اندازی امن مدیر اولیه است و رابط مدیریت کاربران پروفایل را فعال نمی‌کند؛ آن رابط
خارج از محدوده فاز جاری باقی مانده است.
